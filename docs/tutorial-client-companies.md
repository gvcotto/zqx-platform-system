# Tutorial - Empresas cliente de ZQX

Fecha: 2026-07-25

## Objetivo

Ayudar a las empresas que contratan ZQX a usar el sistema sin conocer la parte tecnica.

## Conceptos

- Empresa: espacio privado de trabajo.
- Usuarios: personas autorizadas dentro de esa empresa.
- Clientes: leads, pacientes, estudiantes, cuentas o contactos.
- Agenda: citas, reuniones, entrevistas o reservas.
- Cobros: pagos, saldos pendientes y pagos parciales.
- Asistente: ayuda para preguntas frecuentes e intake.

## Flujo diario

1. Entrar al sistema.
2. Revisar clientes nuevos o pendientes.
3. Confirmar citas/reuniones del dia.
4. Actualizar seguimientos.
5. Registrar pagos o saldos.
6. Revisar notas importantes antes de cerrar el dia.

## Roles

- Admin de empresa: administra operacion y configuraciones permitidas.
- Operador: trabaja clientes, citas, cobros y seguimientos.
- Lectura: revisa informacion sin editar.

## Buenas practicas

- Mantener telefono/email de clientes actualizado.
- Agregar notas claras y breves.
- Registrar pagos el mismo dia.
- Cerrar seguimientos resueltos.
- Pedir apoyo a ZQX si falta un modulo o permiso.
