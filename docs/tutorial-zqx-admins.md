# Tutorial - Usuarios ZQX y admins de empresas

Fecha: 2026-07-25

## Superusuario ZQX

1. Entrar a `system.zqxconsulting.com` con Google.
2. Confirmar rol `ZQX Admin`.
3. Usar `Active company` para cambiar de workspace.
4. Entrar a `ZQX Admin` para revisar empresas, modulos y usuarios.
5. Antes de activar una empresa, validar nombre, contacto, modulos, usuarios y si los datos son demo o reales.

## Admins ZQX

1. Revisar empresas asignadas.
2. Entrar al workspace de la empresa.
3. Validar modulos activos.
4. Revisar clientes, agenda, cobros y asistente.
5. Documentar cambios importantes en la bitacora o ticket interno.

## Admins de empresa

1. Entrar con Google o acceso autorizado.
2. Trabajar solo dentro de su empresa.
3. Crear y actualizar clientes.
4. Crear citas/reuniones desde `Calendar`.
5. Registrar cobros y saldos en `Billing`.
6. Revisar seguimientos abiertos.
7. Usar el asistente para intake/FAQ cuando este configurado.

## Reglas

- No crear usuarios sin confirmar empresa y rol.
- No activar modulos no contratados.
- No mezclar datos demo con datos reales.
- Documentar fecha, motivo y responsable cuando cambie un proceso.
